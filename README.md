# Smart Tool

Tap a tile and get the right tool. Built for touch screens (Cinderbox / Android) but works on PC too.

- Stone -> pickaxe, twig/tree/log -> axe
- Dry crop -> watering can, dirt -> hoe
- Grass -> scythe, monsters in the mine -> sword

## Settings

In-game if you have Generic Mod Config Menu, or edit `config.json`:

- Enable Smart Tool
- Water dry crops
- Scythe for weeds
- Weapon in mines
- Click sound

## Build

Push to `main` and GitHub Actions builds the zip. Grab it from the Actions tab under artifacts.
